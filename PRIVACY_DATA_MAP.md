# Карта данных KZ Price Hunter

Карта описывает хранение в приложении. Фактические настройки среды, журналы прокси и резервные копии обслуживаются отдельно. [Политика безопасности](docs/SECURITY_AND_PRIVACY.md) · [Страница приватности](https://shop.molthun.ru/privacy)

| Данные | Хранение и доступ |
|---|---|
| Аккаунт Telegram | В `users` хранятся идентификатор, имя, username, ссылка на фото и настройки. Профиль, избранное и наблюдения доступны после входа; административный доступ ограничен ролью. |
| Сессии | Сервер хранит хэш токена в `sessions`. Срок — до 30 дней. Cookie HttpOnly, SameSite=Lax и Secure при HTTPS. Выход завершает текущую сессию. |
| Доступ и блокировка бота | Приложение хранит состояние доступа, а для доставки — признак блокировки бота. Разблокировка или новое сообщение боту могут восстановить доставку. |
| Избранное и наблюдения | Личные данные хранятся в БД пользователя. Telegram получает сообщения о срабатываниях и ссылки по настройкам доставки. |
| Очередь уведомлений | Хранит получателя, полезную нагрузку, статус и, для части отправок, номер сообщения. Завершённые записи чистятся по политике приложения. |
| Текст поиска и аналитика | Текст используется для выдачи, разбора и сигналов спроса. Поисковая аналитика агрегирует результаты; у отдельных кэшей и очередей есть свои сроки хранения. |
| Запросы к ИИ | Провайдер получает текст и нужный контекст для задачи: город, выбранные карточки или названия товаров. Свободный текст может содержать введённые пользователем личные сведения. Подключение локальной модели и облачных провайдеров определяется настройками. |
| Каталог и история цен | Сохраняются товары, предложения, ссылки, структурированные характеристики, цены и отметки свежести. Изображения магазина открываются по внешним ссылкам. Полные описания источников используются для извлечения и не записываются в новый каталог; остаток старых записей очищается отдельно. |
| Социальные источники | Исходный текст, OCR, медиа и ссылки на медиа используются временно при извлечении. Сохраняются ссылка и идентификатор публикации, время, краткие данные предложения и основание цены. Для старых записей есть [отдельный скрипт очистки](scripts/scrub_social_content.py). |
| Журналы и диагностика | Администраторам доступны технические журналы и метрики. Типовые секреты редактируются, данные прокси и контейнера обслуживаются отдельно. |
| Резервные копии | Копия базы может содержать аккаунты и настройки пользователя; отдельный конфигурационный архив содержит секреты. Доступ ограничивается правами на хосте. [Хранение и восстановление](docs/PROD_MOVE_P17E.md#ночные-копии) |

## Управление данными

В профиле доступны экспорт (`GET /api/me/export`) и удаление аккаунта (`POST /api/me/delete`). Удаление работает в рабочей базе. Существующие резервные копии хранятся по графику оператора, а переписка в Telegram и данные внешних провайдеров подчиняются правилам этих сервисов.
