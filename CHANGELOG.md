# 📜 История изменений (Changelog) KZ Price Hunter

Все значимые изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

---

## [2.2.0] — 2026-09-17

### Добавлено
- 🤖 **Автономный фоновый мониторинг свежести базы данных**:
  - Фоновый воркер (`auto_scan_background_worker`) непрерывно контролирует возраст каталога.
  - Если база данных старше 1 часа (или значения в настройках), система автономно инициирует фоновое обновление без необходимости ручных действий пользователя.
  - Функция `get_db_freshness()` в `database.py` вычисляет точный возраст самых свежих товаров в секундах.
- 🔄 **Интеллектуальный виджет актуальности базы в шапке**:
  - Кнопка «Сканировать сейчас» убрана из хэдера как избыточная.
  - Вместо неё размещен информативный статус-виджет: отображает состояние базы («База актуальна • обновлена N мин назад • авто через M мин»), а при наступлении 1 часа плавно отображает фоновый прогресс-бар и текущий опрашиваемый магазин.
  - Добавлена аккуратная иконка принудительного обновления для ручного форсирования при необходимости.

## [2.1.0] — 2026-09-17

### Добавлено
- 📍 **Мульти-город и геолокация**:
  - Поддержка выбора города вручную (Астана, Алматы, Шымкент, Караганда, Актобе, Павлодар, Усть-Каменогорск).
  - Автоматическое определение города через браузерный `navigator.geolocation` или IP.
  - Маппинг городов и кодов для сетей Kaspi, DNS, Мечта, Sulpak, Shop.kz, Technodom, Alser.
- 👥 **Независимость сессий пользователей (Multi-User)**:
  - Изоляция пользовательских настроек (выбранный город, активные фильтры поиска, открытые вкладки) в `localStorage` каждого клиента.
  - Параллельная обработка запросов нескольких пользователей без взаимного влияния.
- 🛡 **Cache-First & Anti-DDoS архитектура**:
  - Поиск по умолчанию работает на 100% по загруженной локальной базе SQLite (отклик < 15 мс, нулевой риск бана).
  - Убран принудительный live-парсинг при малом количестве товаров.
  - Добавлен in-memory кэш с TTL 1 час (`SEARCH_CACHE_TTL_SECONDS = 3600`) для предотвращения повторных сетевых запросов.
- 🏷 **Система версионности**:
  - Добавлен модуль `version.py`, журнал `CHANGELOG.md`, эндпоинт `/api/version` и бейджи версии в UI.
- 🎛 **Расширенные фильтры поиска**:
  - Диапазон цен (от / до ₸), исключение аксессуаров, выбор режимов сопоставления (AND / EXACT / OR) и сортировка (по цене / по выгоде).

## [2.0.0] — 2026-09-17

### Добавлено
- 🔴 **Интеграция Kaspi Магазина (`kaspi.kz`)** с умным парсингом цен и очисткой рассрочки.
- 🌐 **Расширение до 10 сетей Казахстана**: DNS, Белый Ветер, Технодом, Forcecom, Sulpak, Мечта, Alser, Эврика, Moon.kz, Kaspi.
- 🔍 **Кросс-поиск лучшей цены (`search_engine.py`)**:
  - Выявление абсолютного лидера по минимальной цене в Астане.
  - Расчет экономии относительно максимальной цены на рынке.
  - Матрица сравнения минимальных цен по каждой розничной сети.
  - Интерактивная Hero-карточка лучшего предложения.
