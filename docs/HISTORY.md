# История проекта и проверок

Для текущей работы используйте [оглавление документации](README.md), [план](DEVELOPMENT_PLAN.md) и свежие записи [журнала передачи](AGENT_HANDOFF.md). Текущую версию среды проверяйте через её `/api/version`.

| Материалы | Назначение |
|---|---|
| [Аудит документации от 13.11.2026](DOCUMENTATION_AUDIT_2026-11-13.md) | Обновление рабочих инструкций и проверка ссылок. |
| [CHANGELOG](../CHANGELOG.md) и [журнал реализации](../ROADMAP_AND_LOG.md) | Изменения по версиям и история внедрения. |
| [Search Platform 2.0](SEARCH_PLATFORM_PLAN.md) | Исходный план перехода. Дата и статус в тексте относятся к постановке задачи. |
| `AUDIT_*`, `FULL_AUDIT_*`, `REAUDIT_*`, `ACCEPTANCE_*`, `REACCEPTANCE_*` | Результат аудита конкретной версии или этапа. |
| `FEATURE_*`, `FIX_*`, `REPORT_*`, `REVIEW_*`, `S2_*`, `P*_AUDIT_*` | Ход реализации и приёмки отдельных задач. |
| [Доказательства проверок](audit_evidence/) | Тестовые журналы и материалы воспроизведения, сохранённые в Git. |

Часть старых записей передачи ссылается на отчёты и артефакты, которые оставались только в рабочем каталоге автора. Для таких записей оставлено имя файла, чтобы его можно было найти по переписке или в исходной рабочей копии.
