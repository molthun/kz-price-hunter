Категория не включается в хэш входа: её уточняет сама проверка. Фактический раздел по-прежнему
ограничивается SQL поиска. Новые снимки кандидатов включают собственную согласованную AI-категорию:
повторная проверка не теряет модельные названия после их переноса в раздел.
Отрицания, совместимость, числовые модели и неоднозначные короткие названия не получают чужие планы.
Старые watch target без оригинального запроса сохраняют строгие записанные фильтры:
автоматически отличить прежний ручной выбор от автоподстановки нельзя; новые target хранят их отдельно.
