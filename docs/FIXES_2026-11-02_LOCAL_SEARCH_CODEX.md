# Исправления LSA-01–09: локальный поиск и расширение каталога

Дата: 02.11.2026. Исполнитель: Codex, прямое поручение владельца после аудита.
Основание: `AUDIT_2026-11-02_LOCAL_SEARCH_CODEX.md`, база `6d47c48`, версии исправлений 6.15.6–6.15.7.
Это исправление и авторская проверка, не независимая приёмка другим агентом.
Прод не меняется; только стенд через bundle, без push в main.

| Замечание | Изменение | Проверка |
| --- | --- | --- |
| LSA-01 | Ручные строгие характеристики отделены от смысловых. Подтверждение полного запроса позволяет не дублировать отсутствующий факт | Две подтверждённые шины, сезон известен одной: выдача и watch — 2; ручной сезон — 1; фасет не придумывает неизвестное |

| LSA-04 | Общий построитель смысловой области для поиска, количества, фасетов и наблюдений | Короткая/полная формулировка; подтверждения добавляются после создания target; цена остаётся ограничением. Существующий durable outbox/idempotency suite |

| LSA-09 | При недоступности/паузе ИИ используется сохранённый план точного запроса или проверенное положительное короткое название | Полная и короткая формулировки сохраняют три подтверждённых результата; цена соблюдается; сеть и новый AI не вызываются |

Категория не включается в хэш входа: её уточняет сама проверка. Фактический раздел по-прежнему
ограничивается SQL поиска. Новые снимки кандидатов включают собственную согласованную AI-категорию:
повторная проверка не теряет модельные названия после их переноса в раздел.
Отрицания, совместимость, числовые модели и неоднозначные короткие названия не получают чужие планы.
Старые watch target без оригинального запроса сохраняют строгие записанные фильтры:
автоматически отличить прежний ручной выбор от автоподстановки нельзя; новые target хранят их отдельно.

## Дополнительное исправление 6.15.7

В реальной проверке 6.15.6 старый план задания расширял шины с 26 до 42 при unavailable.
Неуспешное наблюдение сохранено в `stand-6156-degraded.json`. В 6.15.7 успешный разбор сохраняется
отдельно от плана работающей заявки; кэш ограничен 5000 записями/90 днями с той же фильтрацией
приватных запросов. Для старого плана fallback использует исходные слова + свежие подтверждения,
не доверяя прежнему расширению. Регрессионный тест проверяет сезон и запрет сохранения телефона.
