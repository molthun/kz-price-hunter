# Классификация товаров с характеристиками для локального ИИ — 03.11.2026

## Контекст и основание
- Прямое поручение владельца: «Давай. Характеристики это главное по ним ИИ легче строить фильтра понимать категорию. да и много еще чего».
- Роль: Antigravity (основной разработчик), подхват начатой Codex задачи с полной верификацией и выпуском на стенд.
- Версия: v6.18.8.
- База: `c261967`. Выкладка строго на стенд через git bundle, без push в main и без затрагивания прода.

## Реализованные изменения
1. **`classification_facts.py`**:
   - Приоритезация характеристик: технический тип и форм-фактор (`priority=0`), ключевые аппаратные параметры (процессор, диагональ, чипсет, сокет, память — `priority=1`), общие параметры (`priority=2`), метаданные (`priority=3`).
   - Безопасная фильтрация: исключение паролей, токенов, ключей, cookies, ссылок и тяжелых длинных текстов описания (длина значения <= 300, длина имени <= 80).
   - Вычисление детерминированного SHA256 хеша `attributes_hash`.
   - Группировка источников `source_group` и выявление конфликтующих ключевых типов `conflicts()`.
2. **`product_classification.py`**:
   - Обновление версии промпта: `PROMPT_VERSION = 'category-tags-4-characteristics'`.
   - В промпт локальной модели передаются `verified_source_facts` (с приоритезацией) и `catalog_characteristics`.
   - При наличии `source_facts` или `catalog_facts` эвристический пропуск модели (`rule shortcut`) отключён — модель обязательно анализирует характеристики.
   - Защита от конфликтов: при расхождении характеристик источников или несовпадении правила названия и характеристик карточка переводится в статус `review` (`apply=False`) с понятной причиной для администратора.
3. **`repositories/classification_repo.py`**:
   - Добавлена deterministic SQLite-функция `classification_attributes_hash`.
   - Динамический расчет сигнатуры товара `SIGNATURE` с учетом хеша характеристик.
   - Метод `source(pid)` извлекает `catalog_facts` из `p.attributes_json`.
4. **`web/templates/admin.html`**:
   - В окне ручной классификации администратора добавлен блок «Характеристики каталога для ИИ» для прозрачности принимаемых решений.
5. **Тестирование**:
   - `tests/ai/test_classification_characteristics.py`: 12 тестов на структуру фактов, приоритеты, хеширование и детекцию конфликтов.
   - `tests/ai/test_product_classification_tags.py`: 21 тест на политику и очереди классификации.
   - `tests/frontend/test_frontend_classification_tags.cjs`: 4 браузерных теста (390/1366, dark/light) на отображение характеристик в админке.
