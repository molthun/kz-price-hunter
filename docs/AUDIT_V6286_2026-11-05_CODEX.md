## Известный P2 · Классификатор теряет GRE у RX 9070

**Место:** `catalog_classifier.py:977–984`. Это находка стенда из передачи Claude,
независимо подтверждённая в текущем коде; оптимизация ffcb572 её не вводит и не исправляет.

Для строки `Видеокарта Radeon RX 9070 GRE` функция `canonical_gpu_model()` возвращает
`Radeon RX 9070`. Если сохранить этот результат в `canonical_products.model`, точный
фильтр обычной RX 9070 включает и GRE. Независимый probe создаёт два искусственных товара
с разными названиями, но полученными таким способом одинаковыми model; фильтр возвращает оба.
Контрольная `RX 7900 GRE` распознаётся отдельно.

Причина — общее правило RX 9070 без предшествующего разбора GRE. Исправление только
SQL-фильтра не устранит уже неверно заполненный model. Число затронутых реальных товаров
из передачи автора этим аудитом не пересчитывалось.

**Приёмка отдельной задачи:** различать 9070 / GRE / XT и сохранить 7900 GRE;
применить один разбор в классификации, фасетах и фильтре; подготовить безопасный перерасчёт
ошибочных model на копии БД с сохранением ручных решений, ID, цен и истории.
До отдельного назначения аудит не меняет код или каталог.
