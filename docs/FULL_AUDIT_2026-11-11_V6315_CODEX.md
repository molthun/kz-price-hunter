## C01 · P1 · Автопривязка записывает штрихкод, когда полнотекстовый поиск скрыл второй точный вариант

Резолвер отбирает первые 500 совпадений FTS до проверки точной сигнатуры. В SQLite с 501 совпадением первое и последнее названия полностью одинаковы, остальные 499 содержат дополнительное слово. Резолвер вернул одну карточку. Штатный обработчик результата записал код со статусом `auto_linked`. Стартовая починка сохранила эту запись, потому что видит одну существующую связь и совпадение заголовка с кэшем. Уникальный индекс предотвращает две записи кода, но не защищает от выбора ошибочного варианта. [FTS-выборка](../domain/barcode_resolver.py#L400), [автопривязка](../web/server.py#L1223).

Отдельно запущенный код образа стенда считает «Футболка Nike Sportswear белая S» и «Футболка Nike Sportswear белая M» точным совпадением: одиночные буквы отбрасываются. Прежняя проба с переставленными количествами проходит, размеры S/M — другой вход. На стенде код Tompi связан с одной верной карточкой и дублей кодов нет. [Сигнатура](../domain/barcode_resolver.py#L366).

**Критерий повторной приёмки.** Если выборка достигла ограничения, автозапись допустима только после подтверждения уникальности по полному набору. Сохранить различающие размеры и другие значимые признаки. В пробах с двумя точными вариантами за границей FTS и с S/M ошибочная связь и бейдж отсутствуют. Отдельно проверить существующие автоматические привязки после обновления.

## C02 · P1 · «Поделиться» на странице предложения может отправить цену и ссылку другого города

При открытии `/offer/<id>` без `city` интерфейс использует Алматы. Само предложение загружается по ID и отображается в своём городе. При шеринге Mini App отправляет ID выбранного предложения вместе с общим городом интерфейса. Сервер фильтрует варианты по общему городу и заменяет выбранное предложение самым дешёвым из оставшихся. [Инициализация города](../web/templates/search_first.html#L6667), [запрос Mini App](../web/templates/search_first.html#L7659), [выбор предложения](../web/server.py#L3480).

Независимая сквозная проба в Chrome 390×844 использовала прямую ссылку на актуальное предложение в Астане за **130 000 ₸**. Нажатие «Поделиться» отправило валидный ID с `@astana` и общий город Алматы. Сервер вернул 200, передав адаптеру Telegram **80 000 ₸, Алматы и URL другого предложения**. Bot API перехвачен. В прежней пробе с совпадающим городом точный `offer_id` работает. На стенде прочитано 2 449 канонических товаров с активными предложениями в нескольких городах. Эта цифра описывает область применения сценария, а не число затронутых отправок.

Сохранился и крайний случай старого каталога: свежая запись из Алматы, переданная через `product_id` без канонического ID, получает в карточке регион «Астана» из запроса. Это воспроизведено локальным HTTP-вызовом. [Путь для старых записей](../web/server.py#L3509).

**Критерий повторной приёмки.** При шеринге страницы конкретного доступного предложения карточка, цена, регион и ссылка относятся к этому предложению. Если явно выбранное предложение стало недоступно, интерфейс сообщает об этом или делится ссылкой, соответствующей открытому предложению. Для карточки общего товара сохраняется выбор подходящего предложения по городу. Проверить прямой вход с `@city`, другой общий город, устаревший товар и старый ID.
