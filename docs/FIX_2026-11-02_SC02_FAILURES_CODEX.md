# SC-02: безопасные причины ошибок сборщиков

02.11.2026, Codex по поручению владельца. База a59c7bc, версия 6.18.6.
Один исполнитель, чужие untracked сохранены. Только стенд, без production/main push.

## Поведение

Новые ошибки обхода имеют error_code, phase, page и http_status. Допустимы только фиксированные
коды/этапы, целый номер страницы и HTTP-код; сообщения исключений, URL, заголовки и тела ответов
в эти сведения не копируются. Причины: DNS, timeout, TLS, соединение, HTTP 403/404/429/5xx/прочий,
cooldown, разбор, пустая выдача, неподтверждённый конец и unknown. Проверка Cloudflare у DNS-магазина
сохраняет собственную подтверждённую причину; по общему упоминанию captcha она не угадывается.

Транспорт только наблюдает код ответа/исключение, не меняет возвращаемый ответ/исключение,
retry policy или cooldown. Область контекста изолирована на категорию/страницу и переносится в thread.
Успешный ответ после retry очищает прежний сетевой сбой. Цепочка причин ограничена и защищена от циклов.
Доступный HTTP-код без доказанной причины может сопровождать unknown как метаданные последнего ответа;
сам по себе он не доказывает поломку парсера.

ScanResult получил необязательные error_info. Внутренние старые строки обычных PagedScraper
сохранены для совместимости; сервер перед сохранением/телеметрией заменяет их безопасным описанием.
DNS-магазин формирует безопасную строку непосредственно. Новый компактный SC02-префикс с фиксированной
человекочитаемой подписью сохраняется в существующей source_scans.reason/shop_scans.last_error,
а структурированные поля добавляются в событие категории/ошибки. Миграция схемы не требуется.
Неполный обход, may_retire, baseline, пороги качества и правила сохранения товаров не меняются.
Ранние успешные страницы сохраняются, ошибка последующей страницы не даёт complete.

Мониторинг извлекает только валидный SC02-префикс, в новой админке показывает причину/этап/страницу/HTTP.
Старые RuntimeError/Error не переосмысляются как известная причина, сырые строки в новый обзор не попадают.
Локальный помощник получает допустимые коды действий для сети, паузы, запрета доступа, отсутствующей
страницы, серверной ошибки и разбора. Имена магазинов/сырой текст ошибок ему не передаются,
платного fallback и автоматических изменений нет. Последняя ошибка магазина относится к истории,
а не к прямой проверке его доступности сейчас. Подробные причины категорий доступны в прежнем мониторинге.
