# 📚 Документация KZ Price Hunter

Добро пожаловать в техническую документацию проекта **KZ Price Hunter** — агрегатора цен, мониторинга скидок и межмагазинного арбитража в торговых сетях Казахстана (электроника, супермаркеты, стройматериалы, товары для дома).

Документация структурирована для разработчиков, администраторов и AI-агентов, сопровождающих проект и масштабирующих количество подключенных сетей (до 100+).

---

## 🗺 Разделы документации

1. **[Архитектура системы](ARCHITECTURE.md)**
   - Общая компонентная схема (Web UI, Telegram-бот, AI-сервис, FTS5-поиск, SQLite WAL, Scraper-пул).
   - 24-часовой round-robin шедулер, атомарные аренды (`scheduler_lease`), приоритетные Hot-категории.
   - Модель конкурентности, управление ресурсами и миграции базы данных.

2. **[Руководство по разработке скраперов (Onboarding 100+ магазинов)](SCRAPER_GUIDE.md)**
   - Единый контракт `Scraper Protocol` (`SHOP_NAME`, `scrape`, `close`).
   - Валидация входных данных (`validate_product_item`) и нормализация полей.
   - Выбор транспорта: feeds (A), schema.org (B), internal JSON (C), HTML (D), Playwright headless (E).
   - Политика вежливого сбора данных (polite crawling), таймауты, лимиты и обработка ошибок.
   - Чек-лист подключения нового магазина в систему и написание тестов.

3. **[Нормализация моделей и арбитраж](MATCHING_AND_ARBITRAGE.md)**
   - Алгоритм извлечения `canonical_key` и очистка шума наименований.
   - Защита от ложных совпадений: фильтрация аксессуаров (`is_junk_accessory`), разделение семейств товаров.
   - Детекция аномалий: «пропущенный ноль» (падение в 8–12 раз), глубокие скидки, межмагазинные ценовые вилки.

4. **[Безопасность и приватность](SECURITY_AND_PRIVACY.md)**
   - Авторизация через Telegram Login Widget (HMAC-SHA256).
   - Жизненный цикл сессий, безопасные cookies (`httponly`, `samesite=Lax`) и автоочистка.
   - HTTP Security Headers (`nosniff`, `DENY`, `strict-origin-when-cross-origin`).
   - Что и куда передаётся AI-провайдеру (текст запроса как есть, без профиля Telegram), чего проект не гарантирует; выгрузка и удаление аккаунта.

5. **[Выкат и возврат (RELEASE_AND_ROLLBACK.md)](RELEASE_AND_ROLLBACK.md)**
   - Что проверяется до публикации образа: тесты, браузерные регрессии, секреты, зависимости, репетиция обновления базы, smoke по образу.
   - Порядок выката и порядок возврата, включая случай выросшей схемы и явное описание потери данных.
   - Ручной запуск проверок шлюза (`release_gate.py`) и список пропусков уязвимостей с причиной и сроком.

6. **[Заявка на аудит текущей пачки (AUDIT_REQUEST_BATCH.md)](AUDIT_REQUEST_BATCH.md)**
   - Что именно нужно проверить в этапах P11, P12, P13, P16, P07 V2 и AI-части P09.
   - Заявленные гарантии, по которым идёт проверка, и честный список непроведённого.

7. **[Инвентарь источников (SOURCES.md)](../SOURCES.md)**
   - Детальный технический паспорт всех зарегистрированных магазинов, эндпоинтов и категорий.

8. **[Стандарт адаптеров (SCRAPER_STANDARD.md)](../SCRAPER_STANDARD.md)**
   - Спецификация контракта скраперов и долгосрочный стандарт масштабирования.

9. **[Конфигурация безопасности и Reverse Proxy (SECURITY_CONFIG.md)](../SECURITY_CONFIG.md)**
   - Руководство по настройке reverse proxy (Nginx, прокси NAS и т. п.), Docker, доверенных прокси и CSRF.
