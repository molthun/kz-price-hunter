# Закрытый сайт: гостю только вход — 02.11.2026

Codex по прямому поручению владельца, база 9404db4, v6.16.2.
Один пишущий агент, чужие untracked сохранены. Только стенд, без push main/production.

## Причина и изменение

Auth middleware ограничивал функциональные API. Однако HTML Search-first/dashboard
отдавался целиком, а клиент показывал заглушку лишь в основной области. Меню, город,
нижние ссылки и другие элементы оболочки оставались доступны. Allowlist API использовал
префикс /api/me, что также пропускало дополнительные пути (их собственные проверки прав
оставались, но закрытый режим не был единой границей).

Теперь middleware для гостей/неподтверждённых пользователей закрытого режима отдаёт
отдельный closed_login.html для всех страниц и прямых ссылок. Приложение в этот документ
не включено. В нём только вход через существующий Telegram login/Mini App механизм,
ожидание подтверждения, проверка доступа и выход. Dev login сохранён только в разрешённом
loopback окружении существующей конфигурации. Сторонние API/оплаченные модели не вызываются.

Функциональный API требует подтверждения; исключения входа, /api/me и token-protected
/api/diag сопоставляются точно. Проверки CSRF сохранены. /api/me гостя/pending содержит
только auth/user/maintenance_mode, без списка магазинов/настроек. Liveness/readiness
и статический JS остаются техническими ресурсами существующего сервиса.
Закрытые страницы no-store, Vary Cookie. Подтверждённые/администраторы и открытый режим
сохраняют прежнее поведение. Имеющиеся открытые вкладки получают новый документ после
обновления; API проверяет права на каждом запросе.
