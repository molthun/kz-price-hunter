## Подтверждение остатка R03

Прежний пример `Видеокарта RTX 4070  SUPER 12GB` с model=NULL теперь находится
только фильтром Super и не попадает в обычную 4070. Слитное `4060Ti` также находится
правильным фильтром и не смешивается с базовой моделью.

Независимая матрица включает **144 товара**: девять семейств × восемь разделителей ×
два пути (название при model=NULL и заполненный model). Проверены:

- RTX 4060 / 4060 Ti, RTX 4070 / Super / Ti / Ti Super, RX 7900 XT / XTX, Arc B580;
- слитное написание, один и два пробела, табуляция, LF, CR, U+00A0, U+202F;
- точные множества результатов каждой модели: без пропусков и попадания соседней модификации.

Пробы также подтверждают сохранность исправлений R01/R02/R04: неверная RAM из ёмкости
SSD и инструкция в названии отклоняются; настоящие ОЗУ/SSD принимаются; source_title
обновляется после изменения названия; ноутбук LOQ без слова «ноутбук» не получает
ложную VRAM; отдельная видеокарта сохраняет настоящую видеопамять.

Код теперь применяет одинаковый набор пробельных символов в Python и SQL, включая
проверку исключений суффиксов. Старый перебор ограниченного числа написаний удалён.
Исполняемое доказательство: `docs/audit_evidence/2026-11-05-v6285/probes.py`,
