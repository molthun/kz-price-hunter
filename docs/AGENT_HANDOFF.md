## Действующая модель

Один живой сервер для всех пользователей — рабочая бета. Git хранит принятые исходники и инструкции самостоятельного развёртывания. Публикация Git и обновление живого сервера выполняются отдельно. Вторую сканирующую пользовательскую среду не запускаем.

## Состояние на дату записи

- Принятый код 6.53.2; исправления размеров SZ-04/05/06/07 проверены. Полные авторские прогоны 6.53.2: 3400 тестов на Linux и локально; независимые дробные сценарии проходят.
- Переход на один сервер и перенос основного бота выполнены по разрешению владельца. Прежнее приложение и Watchtower остановлены по отчёту исполнителя.
- Последняя публичная проверка: `shop.molthun.ru` и `shdev.molthun.ru` отвечают 6.53.2. HTTP-редиректа при GET `/api/version` нет. Основной origin — `shop.molthun.ru`.
- Для рабочей схемы обязательны stand + live compose-файлы; [эксплуатация](OPERATIONS.md) объясняет их применение. Внутренние адреса, пути и секреты хранятся в локальной конфигурации администратора.

| Живой Telegram | Проверить `/sizes`, `/search кроссовки 42`, `/прайс` с подтверждением; getMe/polling не заменяет пользовательские сценарии. |
| Размеры у магазинов | Проверить следующий обычный обход Kari/Intertop/KIMEX/Детского мира и актуализацию размеров. Не сбрасывать cooldown ради приёмки. |
| Размеры Kari после переезда (Claude) | На живом сервере размеров Kari нет совсем, у Интертопа — 489 предложений против 2 435 на старом проде. Причина: размеры Kari появились в 6.44.0 после последнего обхода Kari на стенде (03:57Z 22.11); прод успел обойти Kari с размерами. Перенос 22.11 размеры не включал. Готов `scripts/single_live/sizes_migrate.py`: размеры прода только для предложений без размеров (Kari 19 109, Интертоп 1 945; 124 333 строки; <1 с; повтор добавляет 0 — репетиция на копии). Применение к живой БД — после копии и по слову владельца. Иначе размеры вернутся со следующим полным кругом обхода (~24 ч). |
| Спорные исторические данные | Marwin/Forte разбирать по доказательствам и решению владельца, без автоматической очистки. |
