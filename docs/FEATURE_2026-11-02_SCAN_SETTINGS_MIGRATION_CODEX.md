# Перенос настроек: этап 2 — сбор цен

02.11.2026, Codex по прямому поручению владельца. База a831e4e, версия 6.18.2.
Один пишущий агент, чужие untracked сохранены. Только стенд, без production/main push.

## Изменения

В /admin#scanningTool отдельный раздел: точный интервал в минутах/часах/днях,
динамический список подключённых сборщиков, поиск и включение/выключение только показанных.
Скрытые фильтром значения сохраняются. Отключение всех магазинов требует явного подтверждения.
Новый магазин в справочнике сам по себе не подключает сбор: это пояснено в интерфейсе.
Состояние текущего сбора обновляется без перезаписи черновика формы; сохранение не запускает
ручной обход и не останавливает текущий. Точный момент следующего старта не обещается:
показаны существующий режим и базовый интервал волн, действуют очередь и планировщик.
Категории, hot/waves, guarded scheduler и ручной запуск остались в прежних workflow.

Admin-only GET/POST /api/admin/settings/scanning передаёт только интервал и полный bool-map
из config.SHOP_KEYS. Частичный/неизвестный map, лишние поля и неверные типы отклоняются.
Scoped revision проверяется под существующей settings write lock; устаревшая форма получает409
и сохраняет введённое. Изменения модели не конфликтуют со сбором и не перезаписываются им.
Legacy interval/shop controls и два поля общего save payload удалены, оставлена ссылка.
Категорийный handler сохраняет только delta, а не старую копию всех настроек.
Ни ключи, ни платные провайдеры, ни режим нормализации этим этапом не меняются.
