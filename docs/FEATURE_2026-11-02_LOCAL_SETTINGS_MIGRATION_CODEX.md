## Первый этап

В новой /admin#systemTool теперь форма локального подключения:
адрес, имя модели, явные preserve/replace/remove для ключа, текущая пауза/состояние GPU,
короткая проверка сервера и JSON-ответа. Проверка ничего не сохраняет; GET/просмотр формы
не вызывает провайдера. Новая форма сохраняет только local_api_base/local_model/local_api_key.
Сохранённый ключ не приходит в браузер; после сохранения парольный input очищается.
Ответ проверки очищается от фактического ключа, включая несохранённый новый ключ.

Добавлены узкие admin-only GET/POST /api/admin/settings/local-ai и POST /check.
Revision scoped на эти три поля сравнивается под существующей settings write lock;
устаревшая форма получает 409, введённые поля сохраняются до явного обновления.
Валидация общих настроек и CSRF/auth middleware сохранены. Никаких автоматических настроек ключей,
провайдеров или переключений режимов не выполнялось.

Старые input local API/model/key удалены из legacy UI/save payload; вместо них ссылка в новую форму.
Advanced local_normalize_enabled оставлен на прежнем месте: этот этап не меняет процедуру
перехода ключей сопоставления. Старый generic config API остаётся совместимым; revision check
обязателен для новой формы, не является распределённой блокировкой внешнего редактирования файла.

Новые панели сохраняют drafts при переключении; status polling не меняет значения формы.
Сохранение/проверка блокируют повторные нажатия. Refresh несохранённых значений требует явного
подтверждения в интерфейсе. Секреты/настройки на основном стенде тестами не перезаписывались.
