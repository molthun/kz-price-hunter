## 5. План развертывания на Production и план отката

### Порядок выпуска на прод:
1. **Снятие согласованного snapshot рабочей БД**:
   - На сервере прода выполняется `sqlite3 prices.db ".backup prices_pre_v62834.db"`.
2. **Мерж ветки `codex/local-ai-catalog-growth` в `main`**:
   - `git checkout main && git merge --ff-only codex/local-ai-catalog-growth`.
   - `git push origin main`.
3. **Публикация образа Docker**:
   - GitHub Actions автоматически собирает и публикует тег `:latest`.
   - Watchtower (или явный `docker pull`) обновляет контейнер `kz-price-hunter`.
4. **Накат обогащения характеристик**:
   - Выполнение `docker exec kz-price-hunter python3 scripts/enrich_wave10_categories.py /app/data/prices.db`.
5. **Проверка боевого здоровья**:
   - `curl -s https://shop.molthun.ru/api/health` -> `status: ok`.
   - Снятие диагностического снимка `X-Diag-Token`.

### План отката (Rollback):
1. **Откат кода**:
   - `git push -f origin <предыдущий_коммит_main>:main` либо переключение тега Docker-образа на `v6.10.0`.
2. **Откат БД**:
   - Остановка контейнера: `docker stop kz-price-hunter`.
   - Восстановление файла БД: `cp prices_pre_v62834.db prices.db`.
   - Запуск контейнера: `docker start kz-price-hunter`.
