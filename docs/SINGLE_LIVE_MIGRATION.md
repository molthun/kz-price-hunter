## Порядок окна (выполнять только по прямому слову владельца)

Перерыв для пользователей — около 5 минут. Все команды на машине стенда.

1. **Предупредить** пользователей стендового бота о переезде на основной бот и `shop.molthun.ru`.
2. **Остановить автообновление старого прода первым:**
   `docker update --restart=no kz-price-watchtower kz-price-hunter && docker stop kz-price-watchtower`
3. **Остановить старый прод (не удалять):** `docker stop kz-price-hunter`. Контейнер и `~/kzph-prod/data` хранятся 14 дней как точка отката.
4. **Остановить стенд:** `cd ~/kzph-stand && docker compose -f docker-compose.stand.yml stop app`.
5. **Финальные копии:**
   `cd ~/kzph-migration && T=$(date -u +%Y%m%dT%H%MZ) && python3 backup.py ~/kzph-prod/data/prices.db prod_final_$T.db && python3 backup.py ~/kzph-stand/stand-data/prices.db stand_final_$T.db`
6. **Перенос в БД стенда.** Файл принадлежит root, поэтому запуск через образ:
   `docker run --rm --network none -v ~/kzph-stand/stand-data:/app/data -v ~/kzph-migration:/mig kzph-stand:local python /mig/migrate.py /mig/prod_final_$T.db /app/data/prices.db`
   Ожидается `quick_check: ok`. При ошибке транзакция откатывается сама.
7. **Настройки живого сервера** (`~/kzph-stand/.env` и compose):
   - `PUBLIC_ORIGIN=https://shop.molthun.ru`, `APP_URL=https://shop.molthun.ru`;
   - `TELEGRAM_BOT_TOKEN` — токен основного (продового) бота: владелец переносит сам, в отчёты не попадает;
   - в compose добавить порт `"35540:35539"`: тогда DSM-прокси `shop.molthun.ru → 192.168.28.25:35540` попадает на этот сервер без правки DSM;
   - `restart: unless-stopped` вместо `"no"`: живой сервер должен подниматься после сбоя и перезагрузки.
8. **Запустить:** `docker compose -f docker-compose.stand.yml up -d app`, дождаться healthy.
9. **Проверить:**
   - `https://shop.molthun.ru`: версия, вход через Telegram, поиск, карточка с историей цен с сентября;
   - бот: `/start`, `/search кроссовки 42`, `/sizes`;
   - в журнале нет ошибок; через 1–2 часа — один обход магазинов, а не два.
10. **Позже, в DSM:** `shdev.molthun.ru` перенаправить на `shop.molthun.ru`.

## После перехода

- В `origin/main` — только принятые Codex версии с тегами. Watchtower выключен, поэтому push сам ничего не перезапускает.
- Обновление живого сервера всегда явное: тегированный коммит → полный набор в чистом контейнере (`--network none --tmpfs /app/data`) → свежая копия БД (`backup.py`) → `docker compose up -d --build app` → проверка.
- Отдельной второй сканирующей среды нет. Проверки идут в одноразовых контейнерах без сети, на копиях БД.
