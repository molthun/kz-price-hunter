- **Переносить пользователей почти нечего:** наблюдений и избранного нет ни там, ни там. 4 из 5 пользователей прода уже есть на стенде; у одного нужно перенести только настройки. Профили привязаны к Telegram ID, поэтому смена бота профили не теряет.
