По прямому поручению владельца документация приведена к одному действующему порядку: одна рабочая бета, принятый код и инструкции в Git, изолированные проверки без второй пользовательской среды.

- README содержит запуск своей копии и короткую карту документации.
- INSTALL описывает Docker/Python, свою БД, домен, Telegram и отдельное хранение секретов.
- OPERATIONS фиксирует текущую топологию, оба compose-файла, backup и восстановление.
- RELEASE_AND_ROLLBACK разделяет публикацию Git/образа и обновление живого сервера.
- TEST_STAND теперь описывает изолированные проверки; AGENTS обновлён под единственную живую среду.
- Текущий AGENT_HANDOFF сокращён до рабочей очереди. Прежний опубликованный журнал сохранён в истории Git по фиксированному коммиту; локальная полная копия и незакоммиченные отчёты аудита не удалялись. Старые отчёты не используются как текущая инструкция.
- Старые инструкции NAS помечены историческими. Навигация и контекст ведут к актуальным руководствам.
- SINGLE_LIVE_MIGRATION теперь кратко описывает выполненный переход и ведёт к текущей эксплуатации. Операционные команды требуют stand + live.

Команды сверены с Dockerfile, compose, gui.py и существующим процессом CI; принятый код6.53.2 ранее подтверждён отдельными полными прогонами.
