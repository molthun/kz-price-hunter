# Переход на один живой сервер

Переход выполнен 22.11.2026 исполнителем по разрешению владельца. Бывший стенд стал единственной рабочей бетой, основной адрес — `shop.molthun.ru`. История цен и недостающий пользователь перенесены, основной Telegram-бот подключён к рабочей среде. Старое приложение и его Watchtower остановлены по отчёту переключения.

## Что действует сейчас

- Git хранит принятый код и инструкции, а не рабочую БД и секреты.
- Обновление сервера явное; push в main не перезапускает нашу установку.
- Для принятой схемы нужен основной stand-compose и live-дополнение. Их назначение и команды — в [OPERATIONS.md](OPERATIONS.md).
- Сохранение доступа по старому адресу и проверка авторизации отслеживаются в [текущей передаче](AGENT_HANDOFF.md).

## Не повторять миграцию при обновлении

Перенос истории между двумя БД был разовой операцией. Для обычного обновления нужны проверенный код, backup и явное переключение приложения. Скрипты `scripts/single_live/` сохраняются для воспроизведения процедуры на копиях и восстановления контекста, а не для автоматического повторного слияния рабочих данных.

Внутренние реквизиты и резервные копии администратора находятся вне публичной инструкции. Исходный отчёт переключения уже сохранён в [истории Git](https://github.com/molthun/kz-price-hunter/blob/15364973e3cdae617ddb74a235efbecd0eea2691/docs/SINGLE_LIVE_MIGRATION.md).

## Откат

Текущий порядок восстановления — [OPERATIONS.md](OPERATIONS.md#резервная-копия-и-восстановление). Перед возвращением к старой среде сохранить новые записи пользователей и проверить совместимость схемы. Сам по себе архив старого контейнера не гарантирует откат без потери данных.
