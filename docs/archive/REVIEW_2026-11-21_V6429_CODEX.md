## URL-01 — SSD восстановлены только для форм-фактора M.2 (P2)

`config.py`, DNS_CATEGORIES: `nakopiteli-ssd` заменён только на `dd58148920724e77/ssd-m2-nakopiteli/`, при этом название осталось «SSD накопители». Среди других DNS-источников нет отдельного SATA 2,5″. Поэтому наличие товаров M.2 и зелёный тест URL не подтверждают восстановление всего семейства SSD.

Первичный источник для проверки: [раздел SSD DNS с товарами 2,5″ SATA](https://www.dns-shop.kz/catalog/8a9ddfba20724e77/ssd-nakopiteli/). Индексированный текст DNS содержит Kingston A400 и другие 2,5″ SATA. Веб-поиск двумя поисковыми системами подтвердил существование этого адреса в индексе; прямой live-прогон DNSScraper по нему в этой сессии не выполнялся. Текущее наличие конкретного товара не утверждается.

**Исправление и приёмка:** проверить живьём этот листовой раздел, добавить его с `master=storage`, сохранив M.2, либо доказать эквивалентный охват другим источником. Приложить реальные результаты обоих типов SSD. Названия источников должны различать 2,5″ и M.2.

## URL-02 — общий раздел консолей восстановлен без Xbox (P2)

Общий `igrovye-konsoli` заменён PlayStation и портативными консолями. Ветка не содержит источника Xbox, хотя описание мастер-категории включает Xbox. Это неполное восстановление семейства, а не ошибка работы парсера PlayStation.

Первичный источник для проверки: [Консоли Microsoft Xbox DNS](https://www.dns-shop.kz/catalog/17a9f95d16404e77/konsoli-microsoft-xbox/). В индексированном тексте казахстанского сайта есть отдельный раздел и Xbox Series X Digital Edition. Поиск двумя системами подтвердил адрес; прямой HTTP/Playwright smoke не выполнялся.

**Исправление и приёмка:** проверить Xbox реальным DNSScraper и добавить отдельный источник `master=consoles` либо доказать попадание Xbox в другой настроенный источник. Переименовать строку PlayStation из общего «Игровые консоли» в точное название. Контрактный тест должен проверять охват семейств SSD/консолей, а не только повторять новый список URL.
