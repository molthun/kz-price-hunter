# План работ KZ Price Hunter

Актуальная организация с 22.11.2026: один живой сервер, Git как основная копия принятых исходников. [Текущая передача](AGENT_HANDOFF.md) содержит незавершённые проверки; [эксплуатация](OPERATIONS.md) — порядок работы с сервисом.

## Продуктовая основа

- Поиск по смыслу запроса с локальным AI, объяснением пустой выдачи и полезным следующим действием. Требования владельца: [LOCAL_AI_SEARCH_REQUIREMENTS.md](LOCAL_AI_SEARCH_REQUIREMENTS.md).
- Основной путь: поиск → карточка товара → предложения продавцов по городу → переход к продавцу. Избранное, наблюдения, цены и основания скидок должны быть достоверными и проверяемыми.
- Мобильная версия, светлая и тёмная темы входят в приёмку новых экранов. Небольшая визуальная шлифовка выполняется постепенно и не заменяет функциональную проверку.
- Качество источников и склейки, актуальные размеры, уведомления и работа Telegram проверяются вместе с соответствующей функциональностью.

## Текущий порядок

1. Завершить открытые проверки из передачи: адреса/вход, живой Telegram, обычные обходы и актуализация размеров.
2. Сохранять воспроизводимое развёртывание: код, зависимости, конфигурационные примеры и актуальная документация находятся в Git; данные и секреты — отдельно.
3. Новые возможности и исправления принимать на изолированных данных. Живой сервер не используется как постоянно сканирующий тестовый дубль.
4. После принятия публиковать согласованную версию в Git. Обновлять живой сервис явно с backup и проверкой результата.

Новые приоритеты задаёт владелец; этот список не разрешает произвольную реализацию или перезапуск среды.
