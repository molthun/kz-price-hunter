## V660-01 закрыт

После получения семафора call_local_api повторно проверяет local_ai.pause_reason непосредственно
перед HTTP. При паузе место освобождается через finally; usage_sink содержит local_paused и
provider_called=False. Роутер сохраняет паузу как локальный отказ без ошибки/обращения к модели
и продолжает только разрешённый политикой путь.

Прежний независимый queued_pause.py теперь проходит: первый запрос достигает loopback-модели,
второй подтверждённо ожидает слот; после mode=off второго HTTP к local нет, его обрабатывает Gemini
(подменённая функция). Итог — один реальный запрос к имитатору local и один вызов подмены платной.

Дополнительная независимая матрица проверила три политики с тем же ожиданием:

| Выбор | Платный бюджет | Результат ожидающего запроса после off | Возврат после on |
|---|---|---|---|
| auto | Есть | Gemini, без второго HTTP к local | local |
| local | Есть | AIUnavailable, без платного вызова | local |
| auto | Исчерпан | AIUnavailable, без платного вызова | local |

Во всех случаях семафор остаётся пригодным, следующий разрешённый запрос проходит. Штатная
регрессия дополнительно проверяет несколько ожидающих запросов и отсутствие ошибок/фиктивных
обращений в ai_usage для паузы.

## V660-02 закрыт

Нормализация передаёт fallback_from=LOCAL при платной досылке; успешный ответ учитывается
как переход, хотя платный провайдер первый в новом внутреннем run. Тот же признак возвращается
вызывающему в fallback_used. Сам вызов не записывается повторно.

Прежний независимый partial_fallback_usage.py теперь проходит: два названия успешно нормализованы,
в SQLite ровно local/ok requests=1 fallbacks=0 и gemini/ok requests=1 fallbacks=1.
Итого два обращения и один fallback. Функции сетевых провайдеров подменены; нормализация,
маршрутизатор и SQLite-учёт настоящие.

Штатные регрессии подтверждают, что полный ответ local не вызывает платную досылку,
а исчерпанный бюджет не создаёт фиктивного платного обращения. Явный local сохраняет запрет
платного fallback. local_normalize_enabled по умолчанию остаётся False по решению владельца.
