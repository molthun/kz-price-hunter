# Классификационные метки и помощь администратору — 02.11.2026

Исполнитель Codex по прямому поручению владельца. Только стенд; production и push main не разрешены.
Версия 6.16.0. Исходная база 0f97936, чужие untracked сохранены.

## Поведение

Название товара не переписывается. Отдельный тег category_id задаёт классификацию;
canonical category остаётся совместимой проекцией для поиска. Новые/изменённые карточки
поступают в устойчивую очередь; прежние feed pins постепенно пересматриваются.
Явный согласованный тип обрабатывается правилом; противоречия и запрос администратора — локальной моделью.
Уверенный проверенный ответ применяется автоматически. Неясный артикул, низкая уверенность,
неизвестный раздел, противоречие правилу или слишком общий раздел требуют администратора.

В /admin#classificationTool доступны поиск, очередь сложностей, предложение и причина,
ссылки источников, история, ручное назначение, повторная проверка ИИ, снятие закрепления.
Ручной тег защищён от фоновой перезаписи. Новый раздел и фильтры создаются данными после
действия администратора; ИИ не генерирует код сайта. Поле названия товара не редактируется.

Проверка версии карточки защищает от устаревшего решения; lease/generation — от конкурирующих
worker. Ошибка модели оставляет задачу в очереди с задержкой. Пауза сохраняет задачу без ошибки
провайдера. История ограничена 90 днями/200000 событий. Старое последнее решение сохраняется
как legacy без выдуманной версии входных данных. Флаг включён только в stand compose.
