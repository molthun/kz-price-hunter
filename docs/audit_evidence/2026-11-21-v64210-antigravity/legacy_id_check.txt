## 3. Вывод и принятая политика (MW-01 / MW-02)
- Новый API не содержит прежних Magento entity_id, а его собственные 4–6-значные id (1333, 1662, 56255, 221538)
  пересекаются по диапазону со старыми 5-значными Magento ID (например marwin_24909@unknown).
- Поэтому MarwinScraper использует изолированный префикс `marwin_v2_<id>` (0% риска тихой коллизии)
  и новые source_url v1 с чистыми baseline. Старые Magento-записи `marwin_*@unknown` не перезаписываются;
  их последующая очистка после подтверждения работы v1 — отдельное явное решение владельца.
