# KZ Price Hunter

Поиск и сравнение цен в Казахстане. Сайт собирает предложения магазинов, показывает цены по городам, историю цен и скидки. Избранное и наблюдения за ценой доступны после входа через Telegram.

- [Версия на проде](https://shop.molthun.ru/api/version) · [Испытательный стенд](https://shdev.molthun.ru/) · [Версия стенда](https://shdev.molthun.ru/api/version)
- [История изменений](CHANGELOG.md) · [Документация](docs/README.md)

## Как пользоваться

1. Выберите город и введите название товара, модель или описание того, что ищете.
2. Откройте карточку товара, сравните доступные предложения и перейдите к продавцу.
3. Войдите через Telegram, чтобы сохранить товар или создать наблюдение. Условия наблюдения и настройки доставки доступны в профиле.

Цена, наличие и доставка зависят от магазина и города. Перед покупкой проверьте их у продавца. Гостевой доступ может быть ограничен по времени. [Доступ и данные](docs/SECURITY_AND_PRIVACY.md) · [Возможности бота](docs/TELEGRAM_BOT.md)

## Как устроен проект

- Веб-интерфейс и API на aiohttp. Основной путь — поиск, карточка товара и предложения продавцов.
- Источники обновляются в фоне. Каталог, история цен и наблюдения хранятся в SQLite, полнотекстовый поиск использует FTS5.
- В локальной установке можно настроить модель через Ollama или OpenAI-совместимый endpoint. Роль модели и разрешённые резервные провайдеры зависят от задачи и настроек среды.
- Планировщик, уведомления, состояние источников и резервных копий видны в Центре мониторинга администратора.

## Локальный запуск

Понадобится Python 3.14. Выполните из корня репозитория:

```bash
python3.14 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt -c constraints.txt
python -m playwright install chromium
local_data_dir=$(mktemp -d)
DATA_DIR="$local_data_dir" ACCESS_MODE=open python gui.py
```

Откройте [http://localhost:8080](http://localhost:8080). Первый запуск создаёт отдельную пустую базу. Для повторного запуска с теми же данными используйте тот же каталог. Вход Telegram, уведомления и AI подключаются настройками установки. Для локального входа разработчика см. [web/README.md](web/README.md), для серверной конфигурации — [SECURITY_CONFIG.md](SECURITY_CONFIG.md).

```bash
python -m unittest discover -s . -p 'test_*.py'
```
