## 🖥 Запуск Web GUI (Панель управления)

Запустите графический интерфейс одной командой:

```bash
cd kz-price-hunter
./venv/bin/python3 gui.py
```

Браузер автоматически откроет страницу локально: **`http://localhost:8080`**  
А также в локальной сети (с телефона/планшета): **`http://<ваш-локальный-ip>:8080`**

### Что умеет Web GUI:
- 🔍 **Поиск лучшей цены:** кросс-поиск любой техники (Apple Watch, iPhone 16, RTX 5090/4060, MacBook) по всем 11 сетям на базе SQLite FTS5 со скоростью 1–3 мс. Находит **абсолютного лидера по минимальной цене**, рассчитывает экономию относительно дорогих магазинов, строит сводную матрицу цен и выводит полный список предложений по возрастанию цены с прямыми ссылками.
- 🎯 **Межмагазинный арбитраж:** автоматическое обнаружение глубоких скидок по сравнению с другими магазинами (разница ≥ 25% и выгода ≥ 25 000 ₸).
- ⚡️ **YML-каталог Белый Ветер:** мгновенная пакетная загрузка 14 000+ товаров в наличии за пару секунд без риска бана.
- 🚨 **Дашборд аномалий & скидок:** карточки ценовых ошибок («пропущенный ноль», супер-скидки, арбитраж) с фото, старой/новой ценой, экономией и кнопкой моментального перехода.
- 📦 **База товаров:** живой FTS5-поиск по 20 000+ товарам, фильтрация по магазинам, городам Казахстана и ценовым диапазонам.
- ⚙️ **Настройки в браузере:**
  - Настройка Telegram (Token, Chat ID) с кнопкой проверки отправки.
  - Пороги детекции (минимальная цена в ₸, процент падения цены %, минимальная выгода ₸).
  - Управление включением/отключением каждого из 11 магазинов.
  - Настраиваемый интервал автообновления базы (1 ч, 3 ч, 6 ч, 12 ч, 24 ч).
