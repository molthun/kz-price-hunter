# 🎯 KZ Price Hunter

Мониторинг цен в крупнейших сетях электроники Казахстана: поиск ценовых ошибок («пропущенный ноль»), глубоких скидок и межмагазинного арбитража. Результаты выводятся в веб-панели и отправляются в Telegram.

## Текущая версия (v4.0.0)

В проект внедрена полноценная многоуровневая AI-экосистема для работы со всеми 17 магазинами Казахстана:
- **🧠 Умный AI-поиск**: разбор сложных фраз естественным языком на базе Google Gemini Flash и OpenAI REST API (*«ноутбук для учебы до 300к со скидкой»*) с извлечением параметров, брендов, категорий и бюджета без дополнительной нагрузки на CPU Synology NAS.
- **💬 Интерактивный AI-Консультант**: персональный RAG-ассистент по покупкам в Web UI и Telegram. Анализирует реальные цены, наличие, скидки и старые цены по 17 сетям РК и даёт экспертные советы.
- **🤖 Интерактивный Telegram-бот**: легкий Long Polling на `aiohttp` без тяжелых зависимостей (команды `/search`, `/ai`, `/status`, интерактивные кнопки магазинов).
- **⚖️ Каноническая нормализация моделей и 100% арбитраж**: алгоритмическое отсечение магазинного шума (артикулы в скобках, DNS-коды, SIM-суффиксы) и приведение товаров к единому `canonical_key`. Пакетная AI-нормализация для сложных наименований с кэшированием в SQLite и интерактивное модальное окно «Сравнение цен в 17 магазинах».

Каталог насчитывает **58 000+ товаров** в 17 сетях электроники. Сканирование различает полный, ограниченный и неудачный обход с отложенными повторами.

## Возможности

- **🧠 Умный AI-поиск цен** — понимает запросы произвольным языком, автоматически выделяет бренд, модель, категорию и границы бюджета (с тумблером режимов «AI Авто» / «AI Вкл» / «AI Выкл» и баннером инсайтов).
- **💬 Персональный AI-Консультант** — RAG-диалог в веб-интерфейсе и Telegram по всей базе 17 магазинов Казахстана с карточками товаров и ценами.
- **🤖 Интерактивный Telegram-бот** — легковесный Long Polling бот для поиска лучших цен (`/search`), консультаций (`/ai`) и мониторинга системы (`/status`).
- **⚖️ Межмагазинный арбитраж и каноническое сравнение цен** — безошибочное сопоставление моделей (`canonical_key`), поиск вилок цен с экономией и всплывающее окно сравнения цен по 17 сетям.
- **🚨 Аномалии цен** — «пропущенный ноль»: падение цены в 8–12 раз относительно истории цен в базе или зачеркнутой цены на сайте.
- **🔥 Супер-скидки** — падение цены от заданного процента и суммы выгоды.
- **🔍 Поиск лучшей цены** — гибридный поиск по базе FTS5 (кириллические синонимы, опечатки раскладки, стемминг, фильтры по магазинам и категориям).
- **📦 Каталог товаров** — поиск и фильтрация по всей базе товаров.
- **🤖 Автообновление базы** — фоновое мягкое сканирование каталогов.
- **📨 Telegram-алерты** — автоматические уведомления с фото товара при обнаружении ценовых сбоев.
- **📜 Логи (Live)** — просмотр журналов в реальном времени.
- **📍 Регион** — выбор города Казахстана, автоопределение по геолокации или IP.
- **👤 Аккаунты** — вход через Telegram с персонализированными порогами и фильтрами.

## Пользователи и доступ

| Кто | Что доступно |
|---|---|
| **Гость** (без входа) | Аномалии, скидки, поиск по базе и каталог — с настройками по умолчанию |
| **Пользователь** (вход через Telegram) | Личные пороги аномалий, минус-слова, магазины в ленте, Telegram-уведомления, прямой опрос магазинов (Live, не чаще 10 раз за 10 минут) |
| **Администратор** (`ADMIN_TELEGRAM_IDS`) | Плюс общие настройки: интервал сканирования, сканируемые магазины, пороги записи кандидатов, ручное сканирование, логи, блокировка пользователей |

Сканер сохраняет «кандидатов» по мягким общим порогам, а лента, счетчики и Telegram-уведомления каждого пользователя фильтруются по его личным настройкам.

**Настройка входа через Telegram:**
1. Создайте бота у [@BotFather](https://t.me/BotFather) и укажите домен сайта: `/setdomain` → домен вашего сайта.
2. Передайте контейнеру `TELEGRAM_BOT_TOKEN` и свой Telegram ID в `ADMIN_TELEGRAM_IDS` (узнать ID можно у [@userinfobot](https://t.me/userinfobot)).
3. Пользователь входит кнопкой «Log in with Telegram» и разрешает боту писать ему — уведомления приходят в личный чат с ботом.

## Деплой (прод)

```
push в main ──► GitHub Actions: тесты ──► сборка образа ghcr.io/molthun/kz-price-hunter:latest
                                                   │
          Synology (Docker) ◄── Watchtower проверяет образ каждые 5 минут
                 │
          Reverse proxy DSM ──► https://<ваш-домен>
```

- **Любой пуш в `main` уходит на прод примерно через 5 минут.** В CI тесты запускаются до сборки: если они падают, образ не собирается.
- `latest` публикуется **только из `main`**. Теги `vX.Y.Z` собирают образы с номером версии (`:2.9.0`) — на них можно откатить прод.
- Контейнер описан в [`docker-compose.yml`](docker-compose.yml): порт `35539`, данные (база и `settings.json`) в томе `./data` → `/app/data`.
- GitHub не запускает сборки, если за один пуш отправлено больше трех тегов — пушьте теги по одному.
- **Зависимости** зафиксированы: `pip install -r requirements.txt -c constraints.txt`. Обновление версии — правка этих файлов, прогон тестов и новый релиз. GitHub Actions закреплены по SHA; браузерные тесты (`test_frontend*.cjs`) идут в CI перед сборкой образа.
- **AI**: дневной лимит вызовов `AI_DAILY_CALL_LIMIT` (по умолчанию 1500), фоновой нормализации — до 70% лимита.
- **Миграции базы** пронумерованы (`schema_metadata.schema_version`, список `MIGRATIONS` в `database.py`) и выполняются при старте один раз, каждая в своей транзакции. Если есть ожидающие миграции, перед ними автоматически создаётся бэкап `DATA_DIR/backups/prices-pre-vN-<время>.db` (SQLite backup API + `quick_check`). Ошибка миграции откатывает её и останавливает запуск.
- **Откат после миграции**: остановить контейнер, вернуть `prices.db` из `data/backups/prices-pre-vN-*.db` и запустить образ предыдущей версии (`:X.Y.Z`). Только смена образа без восстановления базы не откатывает данные.

## Локальный запуск

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
./venv/bin/playwright install chromium   # нужен скраперам DNS, Технодом и Kaspi
./venv/bin/python3 gui.py
```

Панель откроется на `http://localhost:8080`, в локальной сети — `http://<ip-компьютера>:8080`.

Вход разработчика по умолчанию выключен. Быстрый локальный запуск со входом: `./run_local.sh`, затем откройте `http://localhost:8080` (скрипт включает `ALLOW_DEV_LOGIN=1` и убирает переменные, которые отключают вход). Вручную: запускайте с `ALLOW_DEV_LOGIN=1`, пустыми `ADMIN_TELEGRAM_IDS`, `PUBLIC_ORIGIN` и `APP_URL`, используя отдельный `DATA_DIR`. Кнопка доступна только с прямого loopback-подключения (localhost/127.0.0.1/::1); LAN и reverse proxy не допускаются. Используется отдельная локальная учётная запись, профиль Telegram-администратора не изменяется. Не запускайте приложение на рабочей БД ради проверки: startup вызывает миграции.

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `8080` | Порт веб-панели |
| `DATA_DIR` | папка проекта | Где лежат `prices.db` и `settings.json` |
| `APP_URL` | — | Адрес панели для кнопки «Дашборд цен» в Telegram-уведомлениях и ссылок бота |
| `TELEGRAM_BOT_TOKEN` | — | Токен бота для входа на сайте, уведомлений и интерактивного Telegram-бота |
| `ADMIN_TELEGRAM_IDS` | — | Telegram ID администраторов через запятую |
| `GEMINI_API_KEY` | — | Ключ Google Gemini API для AI-поиска, AI-консультанта и нормализации моделей |
| `OPENAI_API_KEY` | — | Ключ OpenAI API (альтернативный AI-провайдер) |
| `OPENAI_API_BASE` | — | Кастомный endpoint для OpenAI-совместимых шлюзов |
| `ALLOW_DEV_LOGIN` | `0` | Явное включение только для прямого loopback и отдельной локальной учётной записи; отключён при заданном публичном origin или реальных admin IDs. Docker: всегда 0 |
| `PUBLIC_ORIGIN` | `APP_URL` | Канонический origin для CSRF/cookies, без пути: для рабочего сайта `https://shop.molthun.ru`. Без него изменение данных доступно только при прямом локальном подключении |
| `TRUSTED_PROXIES` | пусто | IP/CIDR непосредственного доверенного reverse proxy. Пока не подтверждён, forwarded headers игнорируются |

Подробная настройка границы proxy/CSRF: [SECURITY_CONFIG.md](SECURITY_CONFIG.md). Пример без секретов: [.env.example](.env.example). Карта данных: [PRIVACY_DATA_MAP.md](PRIVACY_DATA_MAP.md); пользовательская страница доступна по `/privacy`.

### Консольный режим

```bash
./venv/bin/python3 main.py --once   # один цикл сканирования
./venv/bin/python3 main.py          # сканирование по кругу
```

> CLI использует общий сканер, настройки интервала и очередь Telegram. После `--once` отложенные повторы сохраняются в базе и продолжатся при следующем запуске CLI или веб-панели.

### Тесты

```bash
./venv/bin/python3 -m unittest test_monitor test_auth_privacy test_bot_privacy test_security_logging test_scraper_reliability test_offer_identity test_scaling
```

Тесты работают на временной базе и не трогают `prices.db` и `settings.json`.

## Настройки

Настройки меняются во вкладке **«Настройки»**. Личные хранятся в базе у каждого пользователя, общие — в `settings.json` внутри `DATA_DIR` (файл не хранится в git). Сервер проверяет значения при сохранении: неизвестные поля отбрасываются, отрицательные числа и неверные типы отклоняются.

| Группа | Кто меняет | Что настраивается |
|---|---|---|
| AI-экосистема | Администратор | Ключи Gemini / OpenAI, тумблер AI, выбор провайдера |
| Детекция аномалий | Пользователь | Типы аномалий, мин./макс. цена товара, мин. скидка (%) и выгода (₸), порог арбитража (% и ₸) |
| Стоп-слова | Пользователь | Минус-слова для аксессуаров, исключение уцененных и б/у товаров |
| Поиск по умолчанию | Пользователь | Сортировка, исключение аксессуаров (прямой опрос магазинов всегда выключен по умолчанию) |
| Telegram-уведомления | Пользователь | Включение, уровень алертов, тестовое сообщение |
| Магазины в ленте | Пользователь | Какие магазины показывать в ленте и уведомлениях |
| Пороги записи кандидатов | Администратор | Мягкие пороги, по которым сканер сохраняет аномалии |
| Сканирование магазинов | Администратор | Интервал автообновления базы, сканируемые магазины |
| Пользователи | Администратор | Список пользователей, блокировка |

## Структура проекта

```
gui.py              — точка входа: запуск веб-панели (aiohttp)
web/server.py       — HTTP REST API, фоновый планировщик, таск Telegram-бота
auth.py             — вход через Telegram, сессии, права доступа, лимиты запросов
ai_service.py       — AI-поиск (Gemini/OpenAI REST), RAG-консультант, пакетная нормализация
telegram_bot.py     — интерактивный Telegram-бот (Long Polling на aiohttp)
model_matching.py   — извлечение canonical_key моделей, сопоставление кросс-магазинных пар
web/templates/      — веб-интерфейс (Tailwind CSS SPA: дашборд, чат-консультант, модальные окна)
scrapers/           — скраперы 17 магазинов Казахстана
detector.py         — детекция аномалий, скидок и межмагазинного арбитража
search_engine.py    — гибридный поиск лучшей цены (FTS5 + синонимы + опечатки)
database.py         — SQLite (WAL + FTS5): товары, история цен, алерты, canonical кэш
config.py           — настройки, категории, города
notifier.py         — Telegram-уведомления
log_manager.py      — перехват логов для вкладки «Логи»
main.py             — консольный режим
test_monitor.py     — набор тестов (46 тестов)
version.py          — версия приложения (v4.0.0)
```
