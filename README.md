## 🖥 Запуск Web GUI (Панель управления)

Запустите графический интерфейс одной командой:

```bash
cd /Users/molthun/Documents/kz-price-hunter
./venv/bin/python3 gui.py
```

Браузер автоматически откроет страницу локально: **`http://localhost:8080`**
А также в локальной сети (с телефона/планшета): **`http://192.168.18.6:8080`** (или ваш локальный IP)

### Что умеет Web GUI:
- 🔍 **Поиск лучшей цены (New!):** кросс-поиск любой техники (Apple Watch, iPhone 16, RTX 4060, MacBook) по всем 10 сетям. Находит **абсолютного лидера по минимальной цене**, рассчитывает экономию относительно дорогих магазинов, строит сводную матрицу цен по сетям и выводит полный список предложений по возрастанию цены с прямыми ссылками.
- 🚨 **Дашборд аномалий & скидок:** карточки свежих ценовых ошибок с фото, старой/новой ценой, экономией и кнопкой моментального перехода в магазин.
- 📦 **База товаров:** живой поиск по 1000+ товарам, фильтрация по магазинам, сортировка.
- ⚙️ **Настройки в браузере:**
  - Настройка Telegram (Token, Chat ID) с кнопкой проверки отправки.
  - Пороги детекции (минимальная цена в ₸, процент падения цены %, минимальная выгода ₸).
  - Чекбоксы включения/отключения каждого из 10 магазинов.
- ⚡️ **Кнопка «Сканировать сейчас»:** запуск принудительного сбора с плавной индикацией прогресса (заливка кнопки цветом) в реальном времени.
