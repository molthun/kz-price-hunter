# KZ Price Hunter

Поиск и сравнение цен в Казахстане: предложения магазинов по городам, история цен, скидки, размеры, избранное и наблюдения с уведомлениями в Telegram.

[Открыть сайт](https://shop.molthun.ru/) · [Скидки](https://shop.molthun.ru/deals) · [Профиль](https://shop.molthun.ru/profile) · [Версия сервера](https://shop.molthun.ru/api/version)

## Развернуть свою копию

В Git хранятся исходный код, зависимости, Dockerfile, конфигурационные примеры и инструкции. Из репозитория можно запустить отдельную установку с пустой базой. Для восстановления существующего сервиса дополнительно нужны его резервная копия данных и секреты — они в Git не публикуются.

Для запуска с Docker Engine и Compose v2:

```bash
git clone https://github.com/molthun/kz-price-hunter.git
cd kz-price-hunter
cp .env.example .env
```

В `.env` укажите свой адрес в `APP_URL` и `PUBLIC_ORIGIN` (для первого локального запуска оба `http://localhost:35539`). Затем:

```bash
docker compose up -d --build kz-price-hunter
curl --fail http://localhost:35539/api/version
curl --fail http://localhost:35539/api/health
```

Откройте [http://localhost:35539](http://localhost:35539). Первый запуск создаёт базу в `./data`. Команда запускает только приложение: сервис автоматического обновления `watchtower` из общего compose не запускается. Для аккаунтов и уведомлений настройте своего Telegram-бота; AI-провайдеры подключаются отдельно.

[Полная установка: Docker, Python, домен, Telegram, данные](docs/INSTALL.md)

## Как пользоваться

1. Выберите город и введите товар, модель или описание.
2. Откройте карточку, сравните предложения и перейдите к продавцу.
3. Войдите через Telegram, чтобы сохранять избранное и наблюдения. «Мои размеры» доступны в профиле и командой `/sizes` бота.

Цена, наличие и доставка зависят от магазина. Перед покупкой проверяйте их у продавца. Возможности доступа определяются настройками конкретной установки.

[Telegram и Mini App](docs/TELEGRAM_BOT.md) · [Доступ и данные](docs/SECURITY_AND_PRIVACY.md)

## Как живёт наш сервис

С 22 ноября 2026 года у проекта **одна пользовательская среда** — бывший стенд, теперь рабочая бета. Основной адрес — `shop.molthun.ru`. Старый `shdev.molthun.ru` также отвечает той же версией. Основной адрес входа и действий с аккаунтом — `shop.molthun.ru`; проверка старых ссылок и канонического перенаправления отслеживается в [текущей передаче](docs/AGENT_HANDOFF.md).

Git — основная копия кода и история принятых версий. Публикация в Git и обновление живого сервера — отдельные действия. Старый прод-контейнер и его Watchtower остановлены; второй обход магазинов не запускаем. Тесты выполняются на временных данных в изолированных контейнерах.
